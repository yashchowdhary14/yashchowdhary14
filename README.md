### 🚀 Projects

#### 🤖 [AgentFlow Enterprise](https://github.com/yashchowdhary14/agentflow-enterprise)
A production-ready multi-agent workflow automation platform that orchestrates specialized AI agents.
- Engineered a **LangGraph** supervisor pattern coordinating Planner, Researcher, Synthesizer, and Evaluator agents.
- Built a hybrid semantic + keyword **RAG** pipeline integrating **Pinecone** vector store and **Redis** cached embeddings.
- Implemented an automated evaluation harness to detect hallucinations and ensure citation-grounded outputs using **FastAPI**.
- Deployed on **AWS ECS Fargate** with containerized **Docker** environments and observability via Langfuse and Prometheus.

#### 🚚 [LogiOps — Logistics Operations SaaS](https://github.com/yashchowdhary14/logistics-operations-saas)
An enterprise-grade multi-tenant SaaS platform designed for modern logistics and fleet management.
- Developed real-time GPS fleet tracking utilizing **Socket.IO** and **Redis Pub/Sub** for high-frequency telemetry streaming.
- Visualized live vehicle data through a custom tracking dashboard using **Leaflet.js** and React.
- Ensured strict multi-tenant data isolation via **PostgreSQL** Row-Level Security (RLS) and Prisma ORM.
- Designed comprehensive Role-Based Access Control (RBAC) supporting Fleet Managers, Dispatchers, and Drivers.

#### 🔍 [JD Resume Matcher](https://github.com/yashchowdhary14/JD_RESUME_MATCHER)
An AI-powered recruiter intelligence system that matches resumes against job descriptions using vector search.
- Built with **Flask** and **FAISS** vector database supporting HNSW, Flat, and IVF indexing structures.
- Computes semantic cosine similarity over 384-dimensional embeddings generated by **SentenceTransformers**.

#### 🎥 [Wav2Lip Video Resume Creator](https://github.com/yashchowdhary14/Video_Resume)
A generative AI video processing pipeline creating synchronized talking head video resumes from audio files.
- Synchronizes lip movements of headshot videos with vocal tracks using **Wav2Lip** deep learning models.
- Orchestrated media ingestion and synthesis endpoints integrated via the **Sync SDK** (Sync.so) API.

#### 🤟 [Sign Language to Text & Speech](https://github.com/yashchowdhary14/Sign-Language-To-Text-and-Speech-Conversion)
A real-time assistive communication engine translating hand gestures into spoken language.
- Tracks hand skeletons dynamically in real-time using **OpenCV** and **MediaPipe** landmarks.
- Employs a custom convolutional neural network (**CNN** in TensorFlow/Keras) achieving 97%–99% classification accuracy.
